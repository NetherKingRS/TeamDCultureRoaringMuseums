Optional student files go here:
- intro.mp4 (your opening video)
- captions.vtt (WebVTT captions)
- narration.mp3 (optional separate student narration)

Set the corresponding paths in config.js or use the in-game Video Studio.
The built-in jazz-inspired music is generated by music.js; no music download is needed.

- jazz.mp3 (your optional music recording)
Set backgroundMusic: "assets/jazz.mp3" in config.js to use it.
